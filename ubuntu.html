Big Steezy — Ubuntu

Ubuntu Server 18.04 hardening reference tailored to the BYU CCDC tryout services.

DoneAlmost DoneReturn to Complete

Baseline / Role

Run hostname, ip addr, and ip route.
Identify machine role and scored services before disabling anything.

Users / Privileges

Review users with cat /etc/passwd.
Keep the required tryout users; check sudo members with getent group sudo.
Check for extra UID 0 accounts.
If you change a scored user's password, submit the required Password Change Request (PCR).

SSH

Review /etc/ssh/sshd_config.
Disable direct root SSH login if not required.
Review root/admin authorized_keys for unknown keys.
Test SSH configuration before restarting/reloading.

Tryout Services — Ubuntu

HTTP: if Apache/Nginx is scored, preserve the expected page/content and check its dependencies.
SSH: keep scored SSH authentication functional while hardening configuration and keys.
FTP: if FTP is hosted here, verify the daemon, authentication, root/home paths, and firewall access.
POP3: if POP3 is hosted here, verify the mail service, authentication, and listening port.
AD/DNS: if Linux is providing DNS or directory-related services, verify them before modifying firewall/network settings.
Before stopping a service, confirm it is not scored and is not a dependency of a scored service.

Services / Ports

Run systemctl --type=service --state=running.
Investigate unfamiliar services; disable only confirmed unnecessary services.
Run sudo ss -tulpn and match listeners to required services.
Investigate unexpected ports/processes.

Firewall

Run sudo ufw status verbose.
Allow required/scored services and restrict unnecessary inbound access.
Do not block source IPs or create scoring-engine-only rules; public services must remain broadly reachable.

Processes / Connections

Run ps aux and review suspicious root processes.
Investigate processes executing from /tmp, /dev/shm, or unusual paths.
Run ss -tunap and inspect unusual outbound connections.

Persistence

Run sudo crontab -l; inspect /etc/crontab and /etc/cron.d/.
Run systemctl list-timers --all.
Review privileged users' SSH authorized keys.
Run find / -perm /6000 -type f 2>/dev/null and investigate unusual SUID/SGID files.

Logs / Threat Response

Review /var/log/auth.log for logins, sudo usage, and failed auth.
Run last, who, and w.
Use journalctl for service/system events.
Do not disable the preconfigured Splunk forwarding to the Black Team indexer.

Quick Integrity / Role

Check suspicious recent changes in /etc and /var/www.
If Apache/Nginx is scored, check service status, web root, permissions, and logs.
Verify AppArmor with sudo aa-status.
Verify required content/authentication still works after changes.
