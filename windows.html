Big Cheesey — Windows

Windows Server 2016 hardening reference tailored to the BYU CCDC tryout services.

DoneAlmost DoneReturn to Complete

Users & Accounts

Review local users with lusrmgr.msc or net user.
Keep the required tryout users; disable only accounts that are truly unauthorized.
Review Administrators, Remote Desktop Users, Backup Operators, and other privileged groups.
If you change a scored user's password, remember that the packet requires a Password Change Request (PCR).

Password / Account Policy

Win + R → secpol.msc → Account Policies → Password Policy.
Set strong minimum length, complexity, history, and disable reversible encryption.
Configure a reasonable lockout threshold/duration without making lockout DoS too easy.

Local Security Policy

secpol.msc → Local Policies → Security Options.
Restrict anonymous SAM/share enumeration and review UAC/Admin Approval Mode.
Review NTLM/SMB-signing settings where compatible.
Review User Rights Assignment: RDP, service logon, network access, debug programs, shutdown.

Tryout Services — Windows

AD/DNS: if this box is providing Active Directory/DNS, verify AD DS/DNS services stay running and LDAP authentication still works.
RDP: keep RDP available if it is being scored; require NLA where compatible and verify allowed users.
HTTP: if IIS/HTTP is hosted here, preserve the expected web content—not just the open port.
FTP: if FTP is hosted here, verify the service, authentication, home/root path, and firewall rules.
POP3: if mail is hosted here, verify the POP3 service, authentication, and listening port.
SSH: if OpenSSH Server is enabled for scoring, harden it without disabling required access.
Before stopping any service, confirm it is not one of the tryout's scored services or a dependency of one.

Services

Win + R → services.msc; inventory running and Automatic services.
Investigate unfamiliar services, executable paths, and service accounts.
Disable only services confirmed unnecessary and not scored.

Firewall / Network

Win + R → wf.msc; verify firewall is enabled for relevant profiles.
Review inbound/outbound rules; remove suspicious or overly broad allows without blocking public scored services.
Run netstat -ano and investigate unexpected listeners/PIDs.
Do not create source-IP blocks or scoring-engine-only rules; the packet requires public services to remain available from all source IPs.

Shares / Permissions

Review shares with fsmgmt.msc, net share, or Get-SmbShare.
Check Everyone/Guest access and NTFS permissions.
Disable SMBv1 where compatible and safe.

Persistence

Review taskschd.msc for suspicious scheduled tasks.
Check Run/RunOnce keys and Startup folders.
Review suspicious services, PowerShell profiles, and Winlogon persistence.

Remote Access

Review RDP; require NLA if RDP is needed.
Review Remote Desktop Users and firewall exposure.
Check WinRM and third-party remote-access software.

Defender / Logging

Verify Defender and real-time protection with Get-MpComputerStatus.
Review Defender exclusions for suspicious paths/processes.
Review Security/System/Application/PowerShell logs in eventvwr.msc.
Do not disable the preconfigured Splunk forwarding to the Black Team indexer.

Role-Specific / Final

If IIS is scored, inspect sites, app pools, web root, logs, and authentication.
If AD/DC, review privileged groups, suspicious users, GPOs, DNS, and service accounts.
Verify required content/authentication still works after hardening—not just that the service process is running.
